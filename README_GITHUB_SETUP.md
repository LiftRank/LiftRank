# LiftRank — GitHub Pages + iPhone

Upload **all files in this folder directly to the root of the GitHub repository** that is published at `liftrank.github.io/LiftRank/`.

Do not upload the folder itself. `index.html` must be at the repository root.

After committing:
1. Open `https://liftrank.github.io/LiftRank/` in **Safari** on iPhone.
2. Delete any previous LiftRank Home Screen icon.
3. Safari Share → **Add to Home Screen**.
4. Launch LiftRank from the new Home Screen icon.

The app is configured for `display: standalone`, an Apple touch icon, a manifest, and a service worker. GitHub Pages must be HTTPS.
